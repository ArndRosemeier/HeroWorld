# The Doctor's posters

Decal images pasted on the piers of the labs and tenements in the mad scientist's quarter
(`hw_gen::urban::menace::fixtures`, drawn by `menaceview.rs`). Made with OpenRouter's
`meta/muse-image` (2026-11-10) at 1:1, scaled to 256 px. Each prompt ended with "square
1950s propaganda poster, bold flat screen-print colours, black, blood red and acid green on
aged cream paper, large legible block lettering, full bleed, the poster fills the whole image
edge to edge, no wall, no frame, no border margin".
