HeroWorld for Windows
=====================

Double-click heroworld.exe to play. Windows 10 or 11 and a graphics card with
Vulkan or DirectX 12 are needed. Keep the assets folder next to the game: the
people and robots are made from it.

Your hero, settings and any crash reports are kept in %APPDATA%\HeroWorld
(the title screen tells you when there is a crash report to send).

Playing with friends
  Host.bat         opens your world to friends; the room code shows top right.
  Join.bat CODE    joins a friend's world by its room code (or an address).
  hw-headless.exe  a world without a window, for a PC that only hosts.

What changed in each version: WHATS_NEW.md.
