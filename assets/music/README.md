# Background music

Pieces that fit the scenery (`soundscape.rs`, `Music`): one plays for where you are, then it is
quiet for a minute or so, then another. A strong change of scene (into the villains' quarter,
down to Molehaven, up into the sky) crossfades to a fitting piece; a colossus fight's own theme
takes over while it lasts. Read from disk and decoded when a piece starts.

Made with OpenRouter on 2026-11-09 with `google/lyria-3-pro-preview` (about three minutes each).
Levelled to -18 LUFS, a 2 s fade in and 4 s fade out, 32 kHz stereo Ogg Vorbis (q 2). Originals:
project files `heroworld/sounds/music/`.
